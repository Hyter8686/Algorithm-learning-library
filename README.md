# 算法总结

LeetCode 刷题笔记。目标只有一个：**刷过的题能再讲一遍，见过的套路能一眼认出来。**

## 目录结构

| 位置 | 放什么 |
| --- | --- |
| `题目/` | 一道题一个文件，文件名 `编号-题名.md`，如 `0001-两数之和.md` |
| `专题/` | 算法知识点：识别信号、套路、代码模板、易错点 |
| `模板/` | 笔记骨架（新建时复制，不用改） |
| `复盘/` | 按月复盘：本月刷了什么、卡在哪、下月计划 |
| `错题本.md` | 反复做错 / 没独立做出来的题，按复习曲线回看 |

## 笔记约定

- **题号补零到四位**：`0001`、`0206`、`1049`，方便按文件名排序。
- 每题固定结构（见 `模板/题目模板.md`）：
  frontmatter + 题意 + **我的思路** + 解法 + 复杂度 + 易错点 + **我的感想** + 更优解 + 相关题。
- **「我的感想」写你自己的话**。我负责整理、补细节、纠错、串专题，不替你编想法。
- 专题笔记记「这类题长什么样」，题解记「这道题怎么做」——不要混着写。
- 代码一律 **C++17**，力扣直接提交能过；只留核心解法，不写 `#include` 和 `main`。
- C++ 约定：`using namespace std;`、容器用 `vector`、`(int)nums.size()` 消警告、索引用 `int`、和/积可能溢出 `int` 的地方用 `long long`。
