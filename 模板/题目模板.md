# 1. 两数之和

## 题意

一句话说清输入、输出、约束（数据范围决定了能不能用 O(n^2)）。

## 我的思路

先写下第一反应，哪怕错。记「为什么这么想」，比记「正确解法」值钱。

- 暴力：枚举所有数对 …
- 想到 XX，但卡在 …

## 解法

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> seen;          // 值 -> 下标
        for (int i = 0; i < (int)nums.size(); ++i) {
            auto it = seen.find(target - nums[i]);
            if (it != seen.end()) return {it->second, i};   // 先查
            seen[nums[i]] = i;                              // 后存
        }
        return {};
    }
};
```

**复杂度**：时间 O(n)，空间 O(n)。

**为什么对**：遍历到 `i` 时，`seen` 里恰好是 `i` 之前的全部元素，查 `target - x` 等价于枚举了所有「一个在前、一个在后」的数对。

## 易错点

- 先查再存，顺序反了会把自己和自己配对（`target = 2*x` 时出错）。
- `unordered_map` 没有 `count` 时用 `find` 比较，别用 `seen[k]`——那会插入一个默认值，把 `size()` 搞脏。
- 返回的是下标不是值。

## 更优解 / 其他思路

- 排序 + 双指针：O(n log n)，但会丢下标，需要额外存原下标。
- 如果数组有序，直接用双指针，O(1) 空间。
