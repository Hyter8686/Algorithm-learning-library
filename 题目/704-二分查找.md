## 题意

升序数组 `nums` 和目标 `target`，找到就返回下标，否则返回 `-1`。

```
输入: nums = [-1,0,3,5,9,12], target = 9      → 4
输入: nums = [-1,0,3,5,9,12], target = 2      → -1
```

## 我的思路

最原始的二分。我试了左闭右开和双闭两种，**最后选双闭**——因为 `while (lo <= hi)` 读起来就是「区间里还有元素就继续」，`lo` 和 `hi` 都是真实下标，`return -1` 的时候不用纠结「越界位置代表什么」。

## 解法（双闭区间 [lo, hi]）

```cpp
int search(vector<int>& nums, int target) {
    int lo = 0, hi = (int)nums.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;      // 不用 (lo+hi)/2，防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

三个配套点，少一个就错：

1. `while (lo <= hi)`——双闭，区间非空条件是 `lo <= hi`。
2. `lo = mid + 1` / `hi = mid - 1`——因为 `mid` 已经检查过了，要从候选区间里**排除**，所以是 `mid ± 1` 而不是 `mid`。
3. `hi` 初值 `n - 1`——双闭区间右端是**能取到的下标**。

## 复杂度

- 时间 O(log n)，空间 O(1)。

## 易错点

- **`while (lo <= hi)` 配 `hi = mid` / `lo = mid` → 死循环**。这是区间写法和收缩方式不配套的典型症状，两者必须成套使用：闭闭配 `mid ± 1`，半开配 `hi = mid`。
- `hi = n`（照抄左闭右开）→ 第一次访问 `nums[n]` 越界。
- `(lo + hi) / 2` 当 `lo, hi` 都是 `INT_MAX` 量级时溢出。
- 循环结束条件别写成 `lo < hi`——那样区间只剩一个元素时会直接退出，`[target]` 这种输入查不到。

## 我的感想

704 是「**找一个具体值**」的二分，判定条件和返回值都是「等于/不等于」。但它的真正价值是让我意识到二分其实有两种形态：

- **精确查找**：`if (a[mid] == target) return mid;`——三路分支，找得到就返回，找不到返回 -1。
- **找边界**：`if (a[mid] >= target) hi = mid - 1;`——两路分支，一路走到黑，最后 `lo` 停下时就是边界。

第二种才是一切的根，第一种只是它的特例（先找 `>= target` 的位置，再核对是不是等于）。35 和 34 就是把这个认识落地的题。

## 更优解

已经是最优。C++ 里可以用

```cpp
auto it = lower_bound(nums.begin(), nums.end(), target);
if (it != nums.end() && *it == target) return (int)(it - nums.begin());
return -1;
```

但手写一遍有价值——后面的二分答案、旋转数组都要靠手写。
