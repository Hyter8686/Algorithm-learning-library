# 2841. 最大和且至少包含 M 个不同元素的 K 长度子数组

## 题意

给数组 `nums`、整数 `m`、`k`，求所有**长度恰好为 k 且不同元素个数 ≥ m** 的子数组里，和的最大值。不存在则返回 0。

## 我的思路

定长窗口的模板题。「长度恰好 k」定死窗口大小，「不同元素个数」是窗口内要维护的第二个量。所以窗口里同时维护两样东西：

1. `sum`：窗口和，进一个加、出一个减。
2. `cnt`：值 → 出现次数，用来算「不同元素个数」= `cnt.size()`。

两个量都是可增删的，`r >= k` 时出、`r >= k-1` 时判 `cnt.size() >= m` 并更新答案。这就是单循环定长模板的直接套用，没有额外变形。

## 代码

```cpp
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        int n = (int)nums.size();
        unordered_map<int, int> cnt;
        cnt.reserve(n * 2);
        long long sum = 0, ans = 0;
        for (int r = 0; r < n; ++r) {
            sum += nums[r];                       // 进
            ++cnt[nums[r]];

            if (r >= k) {                         // 超长就出
                int x = nums[r - k];
                sum -= x;
                if (--cnt[x] == 0) cnt.erase(x);  // 计数归零必须删掉
            }
            if (r >= k - 1 && (int)cnt.size() >= m)
                ans = max(ans, sum);              // 窗口满且种类够
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，空间 O(k)。

## 易错点

- **`--cnt[x] == 0` 时忘了 `erase`**：`cnt.size()` 会统计「值为 0 的键」，`size()` 就不再等于不同元素个数，条件判断全错。这是哈希表 + 滑窗的固定坑。
- `sum` 用 `int`：`nums[i]` 可达 10^9、k 可达 10^5，和能到 10^14，**必溢出**。返回值类型也是 `long long`。
- 判据写成 `cnt.size() > m`（要求「至少 m 个」，是 `>=`）。
- 忘了「不存在则返回 0」——`ans` 初始化为 0 正好，别初始化成 `-1`。
- 用 `set` 存元素也行但常数大；用 `unordered_map` 记次数最好，`reserve` 一下避免 rehash。

## 我的感想

这题验证了一件事：**定长窗口的「窗口内维护什么」可以不止一个量**。我之前以为模板里只有一个 `cnt`，实际上可以是「和 + 计数」同时维护，只要每个量都能 O(1) 增删就行。

也说明 1456 那个单循环骨架（进 → `r >= k` 出 → `r >= k-1` 收）是通用的，换个题只是换 `add`/`remove` 里的内容。
