# 3090. 每个字符最多出现两次的最长子字符串

## 题意

给字符串 `s`，求最长子串，使其中**每个字符出现次数都不超过 2**。

## 我的思路

不定长窗口求最长。约束是「每个字符次数 ≤ 2」，窗口里只需要一个 `int cnt[26]`。

右端进一个后，如果**新进的那个字符**超过 2 次，就收缩左端直到它回到 2。注意：能因这次进入而超标的只有 `s[r]` 本身（其他字符的历史次数没变、窗口只变大），所以 `while` 的条件写 `cnt[c] > 2` 就够；写成通用的 `while (!valid())` 更稳，但这里是同一个意思。

## 代码

```cpp
class Solution {
public:
    int maximumLengthSubstring(string s) {
        int cnt[26] = {0};
        int ans = 0, l = 0, n = (int)s.size();
        for (int r = 0; r < n; ++r) {
            int c = s[r] - 'a';
            ++cnt[c];
            while (cnt[c] > 2) {          // 只有 s[r] 可能超标
                --cnt[s[l] - 'a'];
                ++l;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，l 和 r 各走一遍；空间 O(1)（26 个槽）。

## 易错点

- `while` 写成 `if`：收缩一次可能还不够（虽然这题一次就够，因为每次只多一个字符——但别养成习惯）。
- **收完再更新答案**：`ans` 必须写在 `while` 之后，否则会把不合法窗口算进去。
- 用 `unordered_map<char,int>` 也行但没必要，26 个字母用定长数组快得多，也避开 `erase` 的坑。
- `int n = s.size()` 直接写会报「有符号/无符号比较」，要 `(int)s.size()`。

## 我的感想

这是「不定长求最长」模板最干净的一次：进 → 不合法就缩 → 收答案。没有边界（`r - l + 1` 就是长度），没有换算，没有额外结构。

有个细节值得记：**能破坏合法性的只有「刚进来的那个元素」**。这在很多题里成立（3090、3、1004 都是），因为窗口只增加了一个元素，其他元素的状态没变。想到这一点，`while` 里的条件就能写得很轻，不用每次全量检查。
