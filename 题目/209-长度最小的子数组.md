# 209. 长度最小的子数组

## 题意

正整数数组 `nums` 和目标 `target`，求**和 ≥ target** 的最短连续子数组长度。不存在返回 0。

## 我的思路

不定长窗口求最短。约束 `sum >= target` 对「窗口变大」是单调的（元素都是正数，加进来只会让和更大），所以：

- 右端进一个，和变大；
- **只要还合法，就尝试缩左端**，每缩一次都可能是更短的答案，缩到不合法为止；
- 答案在 `while` **里面**更新。

这题和「求最长」的流程差别就两点：答案更新在 `while` 里，`ans` 初始化为「不可能的大」（`n + 1`）。

## 代码

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = (int)nums.size(), ans = n + 1, l = 0;
        long long sum = 0;
        for (int r = 0; r < n; ++r) {
            sum += nums[r];
            while (sum >= target) {              // 合法就试着缩
                ans = min(ans, r - l + 1);
                sum -= nums[l++];
            }
        }
        return ans == n + 1 ? 0 : ans;           // n+1 表示没找到
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)。

## 为什么 `ans = n + 1` 而不是 `INT_MAX`

用 `n + 1` 当「无解」哨兵有两个好处：

1. 不用 `<climits>`，也不会出现 `INT_MAX` 参与运算的意外；
2. 返回值判断写成 `ans == n + 1 ? 0 : ans`，一眼看出「没更新过」。

而且任何真实答案都 ≤ n，所以 `n + 1` 一定大于所有可能答案，作为初值是安全的。

## 易错点

- **答案写在 `while` 外面**：那就变成「收缩后的长度」，不是最短的。
- 求最短时 `ans` 初始化成 0（`min(0, x)` 恒为 0）。
- `sum` 用 `int`：`nums[i] ≤ 10^5`、n 到 10^5 → 和可达 10^10，溢出。
- 忘记了「不存在返回 0」，直接返回 `ans`。
- 把「≥ target」写成「> target」。

## 我的感想

这是求最短模板的标准题，我拿它把「最短版」的骨架固定下来了：

```cpp
for (int r = 0; r < n; ++r) {
    进(r);
    while (合法()) { ans = min(ans, 长度); 出(l); }
}
```

和最长版的分工是：**最长在「不合法」时缩，最短在「合法」时缩**；最长答案写在循环外（缩完之后），最短写在 `while` 里（缩的过程中）。这两句一记，模板就不会写混。

顺带一个反例意识：这题能滑，是因为**元素全为正**。一旦允许负数，`sum >= target` 对「窗口变大」不再单调（加个负数会让和变小），滑窗立刻失效，得换前缀和 + 单调队列（[862](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)）。这个前提不能忘。
