# 1343. 大小为 K 且平均值大于等于阈值的子数组数目

## 题意

给整数数组 `arr`、窗口长度 `k`、阈值 `threshold`，返回**长度恰好为 k 且平均值 ≥ threshold** 的子数组个数。

约束：`1 <= arr.length <= 10^5`，`1 <= arr[i], k, threshold <= 10^4`。→ O(n)。

## 我的思路

「长度恰好为 k 的子数组」= 定长窗口，枚举所有窗口起点即可，窗口数量是 `n - k + 1`，所以外层只需要一次滑动。

## 核心一步：把「平均值」换成「和」

$$\frac{sum}{k} \ge threshold \iff sum \ge k \times threshold$$

这一步至关重要，原因有三：

1. **完全避开浮点**。`double` 表示 1/3 这种值有误差，`sum / k >= threshold` 在边界上可能判错；力扣的判题数据里明确有卡浮点的用例。
2. 比较变成整数比较，快。
3. 阈值 `k * threshold` 是常量，可以提到循环外，每个窗口只维护 `sum` 一个变量。

**`k * threshold` 要用 `long long`**：`k` 最大 10^5、`threshold` 最大 10^4，乘积 10^9，虽然勉强在 int 内，但和窗口和相加比较时容易踩线，直接用 `long long` 更省心。

## 代码

```cpp
class Solution {
public:
    int numOfSubarrays(vector<int>& arr, int k, int threshold) {
        int n = (int)arr.size();
        long long sum = 0, need = (long long)k * threshold;
        int ans = 0;
        for (int r = 0; r < n; ++r) {
            sum += arr[r];                          // 进
            if (r >= k) sum -= arr[r - k];          // 超长就出
            if (r >= k - 1 && sum >= need) ++ans;   // 窗口满且达标
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)。

## 易错点

- 用 `double avg = (double)sum / k;` 比较，浮点误差导致边界用例 WA。**先乘过去**。
- `need = k * threshold` 写成 `int` 乘法，某些数据下溢出成负数，答案会爆炸。
- 计数条件写成 `r > k` 而不是 `r >= k - 1`，少算最后一个窗口 / 第一个窗口。
- 忘了 `ans` 是计数不是最值（这题不需要 `max`）。
- 窗口数一共 `n - k + 1` 个，如果最后发现差 1，先数一遍手工小样例。

## 我的感想

这题看着是「平均值」，实际是「和」——**题目里的除法和开方，第一反应都应该是「能不能乘过去」**。乘过去之后，问题就退化成了 1456 那种最简单的定长窗口。
