# 1004. 最大连续 1 的个数 III

## 题意

0/1 数组 `nums`，最多把 `k` 个 0 翻成 1，求最长全 1 子数组长度。

## 我的思路

「翻转」不用真的翻转——能把它翻过来的前提是**这一段里 0 的个数不超过 k**。所以约束是「窗口内 0 的个数 ≤ k」，求最长窗口。和 1493 只差一个常数，而且不用减 1（最多 k 个，不是必须）。

## 代码

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int n = (int)nums.size();
        int ans = 0, l = 0, zeros = 0;
        for (int r = 0; r < n; ++r) {
            if (nums[r] == 0) ++zeros;
            while (zeros > k) {
                if (nums[l] == 0) --zeros;
                ++l;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)。

## 一个可选的优化：l 不求最短

这题求的是**最长**，所以 `l` 没必要真的缩到「刚好合法」——只要窗口长度不再增长就行。可以把 `while` 改成 `if`：

```cpp
if (zeros > k) { if (nums[l] == 0) --zeros; ++l; }
```

这样窗口长度只会「持平或 +1」，答案就是最终窗口长度。**求最长时合法窗口可以留冗余，因为我们要的是长度下界**。但求最短绝不能用这招（那会漏掉最短解）。这个技巧在小林coding 那类写法里很常见，不过初学先老老实实写 `while`，理解清楚再省。

## 易错点

- `while (zeros > k)` 里忘了只在 `nums[l] == 0` 时 `--zeros`。
- **`k == 0`** 时退化成「最长全 1 段」，代码不用特判就能对——这是这套写法的好处。
- 答案更新在收缩之后；写成 `r - l` 少加 1。
- 把「最多 k 个」写成「恰好 k 个」（那是另一个题，要额外处理）。

## 我的感想

和 1493 摆在一起看，这题的「翻译」更自然：翻转 = 容忍 0。两题的差别只有两处——「≤ 1」vs「≤ k」，以及有没有那个 `- 1`。

我现在会把这类题归成一个句式：**「最多 / 至少对窗口里某种元素做 X 次操作」→ 变成「窗口内该元素个数 ≤ / ≥ 常数」**。翻译完就是纯模板。
