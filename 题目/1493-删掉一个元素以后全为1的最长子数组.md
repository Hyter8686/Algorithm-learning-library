# 1493. 删掉一个元素以后全为 1 的最长子数组

## 题意

给 0/1 数组 `nums`，**必须删掉恰好一个元素**，返回删完后最长的全 1 子数组长度。删完后数组长度减一。

## 我的思路

「删掉一个元素后全为 1」等价于：原数组里找一段子数组，其中 **0 的个数 ≤ 1**，且删的就是那个 0（如果没有 0，就随便删一个 1）。所以是「不定长求最长，约束 = 窗口内 0 的个数 ≤ 1」。

答案要减一：因为必须删掉一个元素，即使窗口全是 1，也只能得到 `len - 1`。

## 代码

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int n = (int)nums.size();
        int ans = 0, l = 0, zeros = 0;
        for (int r = 0; r < n; ++r) {
            if (nums[r] == 0) ++zeros;
            while (zeros > 1) {
                if (nums[l] == 0) --zeros;
                ++l;
            }
            ans = max(ans, r - l + 1 - 1);   // 必须删掉一个元素
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)。

## 另一种视角：两段式

这题也能按上次 1052 学到的「两段式」拆：

```
答案 = 全 1 的总数 + 窗口内 (0 的个数 - 1 的个数) 的最大值
```

因为把窗口里的 0 换成 1、同时窗内的 1 会「挤掉」原本就在外面的 1。两个视角都对，滑窗版更直接，两段式版更能解释「为什么答案长这样」。**同一个问题有两条路，说明它的结构被吃透了**。

## 易错点

- **忘了减 1**：全 1 的数组（如 `[1,1,1]`）答案应是 2，不是 3。这是这题唯一的官方陷阱，样例里就有一个全 1 的用例专门抓这个。
- 「删除」不等于「可以不删」：不能返回不减 1 的结果，所以 `ans` 初值用 0 没问题，但别加 `+1`。
- 窗口收缩时只有在 `nums[l] == 0` 才减 `zeros`，写成无条件 `--zeros` 会错。
- 收缩完再更新答案，顺序别反。

## 我的感想

这题教我的是「**把操作翻译成约束**」：题目说「删掉一个元素」，我不该去真的模拟删除，而该问「删完之后剩下的那段长什么样」——于是得到「0 的个数 ≤ 1」这个窗口约束。翻译对了，剩下的就是模板。

`- 1` 那一下也是同一个道理：题目要求**必须**删，这个「必须」在答案里就是减一，不能因为「全 1 时删了可惜」就偷偷不减。
