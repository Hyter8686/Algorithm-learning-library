# 2379. 得到 K 个黑块的最少涂色次数

## 题意

给字符串 `blocks`（只含 `'W'`、`'B'`）和整数 `k`。每次操作可以把一个 `'W'` 涂成 `'B'`，求得到**连续 k 个黑块**的最少操作次数。

## 我的思路

「连续 k 个」= 长度恰好 k 的窗口。对某个窗口，要把它变成全黑，需要涂的次数**恰好就是这个窗口里 `'W'` 的个数**——因为已有的 `'B'` 不用动，每个 `'W'` 涂一次。

所以问题变成：**长度为 k 的所有窗口中，`'W'` 个数的最小值**。

这是个「求最小」的定长窗口，维护的变量是 `w`（窗口内白块数），进一个白块就 `+1`，出一个白块就 `-1`。

## 代码

```cpp
class Solution {
public:
    int minimumRecolors(string blocks, int k) {
        int n = (int)blocks.size();
        int w = 0, ans = INT_MAX;
        for (int r = 0; r < n; ++r) {
            if (blocks[r] == 'W') ++w;                        // 进
            if (r >= k && blocks[r - k] == 'W') --w;          // 出
            if (r >= k - 1) ans = min(ans, w);                // 收答案
        }
        return ans;
    }
};
```

**复杂度**：时间 O(n)，空间 O(1)。

## 一个更省事的等价写法

窗口里白块数最少，等价于黑块数最多。也可以直接维护黑块数求最大，答案再用 `k - maxBlack`——两种都对，但本题直接数白块更贴合题面（「要涂几次」= 白块数）。

## 易错点

- **求最小却把 `ans` 初始化成 `0`**：`min(0, 任何正数)` 永远是 0，直接错。求最小初始化为 `INT_MAX`，求最大初始化为 `0`（或 `INT_MIN`）。
- 「出」的判断写成 `r > k`，导致窗口长度变成 k+1。
- 只数了 `'B'` 却忘了最后要 `k - cnt`。
- 认为「需要把若干个 W 连成一片，可能跨窗口」——不需要，最优解一定落在某个长度 k 的窗口内（反证：任何一段连续 k 个黑块都覆盖某个窗口）。
- `k == n` 时只有整串一个窗口，答案就是 `count(blocks, 'W')`，循环里也自然成立。

## 我的感想

这题让我看到定长窗口的另一种形态：**答案是「窗口内某个计数的最值」，而不是「窗口本身的和/长度」**。只要「进一个、出一个」能 O(1) 更新这个计数，定长窗口就成立。

「要涂几次 = 窗口里几个 W」这一步转换是本题的全部，写代码反而是模板。**先想清「答案对应窗口里的什么量」，再套模板**——这是我这几天做定长窗口题最大的体会。
