# 3795. 不同元素和至少为 K 的最短子数组长度

## 题意

给正整数数组 `nums` 和整数 `k`，找一个**连续非空子数组**，使其**不同元素之和**（同一个值只算一次）≥ `k`，求最短长度；无解返回题面规定的那一个标记（-1）。

例：`nums = [1, 2, 1, 3]`，`k = 4` → 取 `[1, 3]`，不同元素和 `1 + 3 = 4`，长度 2。

## 我的思路

仍是「不定长求最短」，但窗口里要维护的量从「和」换成了「**去重和**」。这是本题唯一的新东西。

去重和的可增删性：

- **进**一个 `x`：如果 `x` 之前没出现过（计数 0 → 1），`sum += x`；否则和不变。
- **出**一个 `x`：如果 `x` 的计数减到 0，说明窗口里再也没有 `x` 了，`sum -= x`；否则和不变。

所以还是要一个 `unordered_map<int,int>` 记次数，`sum` 在计数**跨过 0/1 边界**时才变。这跟 2841 的「`cnt.size()` 当不同元素个数」是同一套基础设施，只是这里要把「值」也累加进去。

正确性依赖两点：①加元素只会让去重和变大或不变（单调）；②出窗时能精确回退。两个都成立，所以直接套最短模板。

## 代码

```cpp
class Solution {
public:
    int solve(vector<int>& nums, long long k) {   // 函数签名按题面
        int n = (int)nums.size(), ans = n + 1, l = 0;
        unordered_map<int, int> cnt;
        long long sum = 0;                        // 窗口内的去重和
        for (int r = 0; r < n; ++r) {
            if (cnt[nums[r]]++ == 0) sum += nums[r];   // 首次出现才加
            while (sum >= k) {
                ans = min(ans, r - l + 1);
                int x = nums[l++];
                if (--cnt[x] == 0) {              // 窗口里彻底没有 x 了
                    sum -= x;
                    cnt.erase(x);                 // 可选，省内存也避免脏键
                }
            }
        }
        return ans == n + 1 ? -1 : ans;
    }
};
```

**复杂度**：时间 O(n)（每个下标进一次、出一次），空间 O(不同元素个数)。

## 核心：为什么「出窗」时不能无脑减

普通的窗口和，出窗就是 `sum -= x`。这里不行：`x` 可能在窗口里还有别的副本。所以必须先用计数判断「这一份是不是最后一份」：

```cpp
if (--cnt[x] == 0) sum -= x;    // 对
// sum -= x;                    // 错：重复元素会被减多次
```

反例：`nums = [2, 2, 3]`、`k = 5`。窗口 `[0,2]` 去重和 5 合法，左端出 `2` 时如果直接减，和变成 3——但窗口 `[1,2]` 里还有一个 `2`，去重和仍然是 `2+3=5`。

## 易错点

- 上面那条：出窗要判断「计数归零」才减。
- 进窗同理，必须判断「首次出现」（`cnt[x]++ == 0` 才加）。
- `sum` 用 `long long`（`k` 与去重和都可能很大）。
- 无解标记别写错（题面是 -1 还是 0，看题）。
- `cnt.erase(x)` 删不删都行，但**删了之后就不能再用 `cnt.size()` 当不同元素个数**去算别的量——两者会冲突，本题只用到 `sum`，所以安全。

## 我的感想

这题让我确认了一件事：**滑窗的难点不在骨架，在「窗口里那个量能不能 O(1) 增删」**。去重和一开始看起来像「不可逆」的量（跟窗口最大值类似），但它其实可逆——因为它只取决于**每个值出现没出现**，而这个状态用计数就能精确回退。真正不可逆的是「原来看最大值靠排序/比较得到」那种量。

顺带串起来：2841 用 `cnt.size()` 当「不同元素个数」，这题用 `cnt[x] == 0` 判断「值是否退出窗口」，本质是同一张表提供两种信息。
