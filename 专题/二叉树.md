# 二叉树

## 什么时候想到它（识别信号）

- 输入是树，问**路径 / 深度 / 节点数 / 是否对称 / 是否 BST**。
- 需要「从子节点往上传信息」→ 后序（自底向上）。
- 需要「从根往下带约束」→ 前序（自顶向下）。
- 要按层处理 → BFS。

力扣给的节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *l, TreeNode *r) : val(x), left(l), right(r) {}
};
```

## 一、递归：先想清三个问题

1. **函数返回什么**？（深度？是否合法？子树信息？）
2. **子问题怎么合并**？
3. **base case 是什么**？（`root == nullptr` 返回什么）

绝大多数二叉树题卡住，不是不会写递归，而是**没定义清楚「返回值代表什么」**。

## 二、遍历模板

### 前/中/后序（递归）

```cpp
void dfs(TreeNode* root) {
    if (!root) return;
    // 前序：处理 root
    dfs(root->left);
    // 中序：处理 root（BST 题在这里取值 → 有序）
    dfs(root->right);
    // 后序：处理 root（此时左右子树都已知）
}
```

### 层序（BFS）

```cpp
queue<TreeNode*> q;
if (root) q.push(root);
while (!q.empty()) {
    int sz = q.size();              // 这一层的节点数，必须先存下来
    for (int i = 0; i < sz; ++i) {
        TreeNode* node = q.front();
        q.pop();
        // 处理 node
        if (node->left)  q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
```

`int sz = q.size()` 是分层的关键；在循环条件里直接写 `q.size()` 会因为一边 push 一边变化而错乱。空树用 `if (root)` 挡住，否则空指针入队。

## 三、两类递归的分水岭

| 类型 | 方向 | 适合 |
| --- | --- | --- |
| 自顶向下 | 参数往下传（当前路径、深度、上下界） | 路径和、判断 BST（传 min/max） |
| 自底向上 | 返回值往上带 | 求高度、直径、是否平衡、最大路径和 |

**自底向上不好写时，先写自顶向下 + 全局变量**，能过再说。

C++ 里「全局变量」用成员变量（`int ans = 0;` 写在 class 里），别用真正的全局变量——力扣会多次调用同一个 Solution 对象/多个用例共用进程，容易被污染。

## 四、BST（二叉搜索树）

- **中序遍历是升序**——这是 BST 唯一的万能钥匙。
- 判断合法 BST：传区间 `(low, high)`，不要只比较父子（经典坑：只比 `左<根<右` 会漏掉「左子树的右节点比根大」）。
- 区间上下界要用 `long long`，节点值可能是 `INT_MIN` / `INT_MAX`。
- 删除节点分三种情况（叶子、单子、双子→用右子树最小值替换）。

## 易错点

- 空树（`root == nullptr`）的返回值要想清楚：求深度返回 `0`，求路径返回 `{}`，求「是否」返回 `true`。
- 求「路径」类题目，**路径可以不经过根**，所以常常需要一个成员变量 `ans` 在外层更新。
- 层序遍历忘了 `if (root)`，空树会崩。
- **递归深度**：链状树 10^5 个节点会把 C++ 栈打爆（栈溢出直接 RE），要么改迭代，要么加 `#pragma`（力扣上没用）——只能改迭代。
- 返回 `vector` 时用 `res.push_back(...)`，别返回局部变量的引用。
- 传 `TreeNode*` 就够了，别写 `TreeNode*&`（除非要改指针本身）。
