# 链表

## 什么时候想到它（识别信号）

- 题目给的是 `ListNode*`，不能随机访问，只能顺着 `next` 走。
- 要**原地**改结构（反转、重排、删节点），O(1) 空间。
- 要**合并 / 分割 / 排序**链表 → 归并排序（链表场景下比快排好写，因为不需要随机访问）。
- 判环、找中点、找倒数第 k 个 → 快慢指针。

力扣已经给了节点的定义，不用自己写：

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};
```

## 三个保命习惯

1. **哑节点（dummy）**：只要可能「删头 / 插头 / 头会变」，一律用栈上的 `ListNode dummy(0, head);`，最后返回 `dummy.next`。这一招能消灭 80% 的头节点特判，而且**不需要 `new`**（不用担心泄漏）。
2. **改指针前先存 `next`**：`ListNode* nxt = cur->next;` 写在最前面。
3. **画图**：三个指针的赋值顺序画一遍，比背模板可靠。

## 模板

### 反转链表（迭代）

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode *prev = nullptr, *cur = head;
    while (cur) {
        ListNode* nxt = cur->next;   // 1. 存
        cur->next = prev;            // 2. 改
        prev = cur;                  // 3. 移
        cur = nxt;
    }
    return prev;                     // 注意返回 prev，不是 cur
}
```

### 删除倒数第 n 个

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);
    ListNode *fast = &dummy, *slow = &dummy;
    for (int i = 0; i < n; ++i) fast = fast->next;   // fast 先走 n 步
    while (fast->next) {
        fast = fast->next;
        slow = slow->next;
    }
    slow->next = slow->next->next;   // 此时 slow 指向待删节点的前一个
    return dummy.next;
}
```

### 合并两个有序链表

dummy + 尾指针，`while (l1 && l2)` 挑小的接上，最后把没走完的那条整段接上（不用再循环）。

### 反转区间 [left, right]

先走到 `left-1` 位置，再反转 `right-left+1` 个节点，最后把三段接回去——接缝处的两个指针最容易写错，先在纸上标好「前段的尾」「反转后的头」「反转后的尾」「后段的头」。

## 易错点

- 返回 `head` 还是 `dummy.next`：只要用了 dummy，就返回 `dummy.next`。
- 反转后**原来的头变成了尾**，它的 `next` 必须置 `nullptr`，否则成环，力扣会报「超出内存/循环」。
- 写 `while (fast && fast->next)`，漏了 `fast` 会在偶数长度、`fast` 已经为 `nullptr` 时解引用崩掉。
- 空链表（`head == nullptr`）和单节点要单独在脑子里跑一遍。
- 用 `new ListNode` 建 dummy 最后要 `delete`（力扣不查，但工程里会漏内存）；用栈上的 `ListNode dummy(0, head)` 就不用管。
- 指针题调试时，先写个打印链表的函数，比盯着代码看快得多。
