# 贪心

## 什么时候想到它（识别信号）

- 求**最值**，且感觉「每一步都选当前最好的，最后就最好」。
- 排序之后答案自己就出来了（区间题尤其）。
- 问题有**拟阵 / 交换论证**的直觉：把最优解逐步换成贪心解，不亏。

**贪心最大的风险是「感觉对但错了」**。判断方法只有两个：

1. 找反例（举几个小数据手算）。
2. 想证明：交换论证（把最优解里第一个和贪心选择不同的步骤换掉，证明不更差）或「保持贪心最优」。

想不出证明又找不到反例 → 老老实实写 DP / 搜索。

## 核心思想

只在「局部最优可以推导全局最优」时成立。所以贪心题真正的难点不是写代码，是**找到那个「按什么排序」**。

一句经验：**贪心题 90% 的第一步是排序**。排序的 key 就是贪心策略本身。

## 常见套路

### 1. 区间调度（按右端点排序）

选最多的不重叠区间：

```cpp
sort(intervals.begin(), intervals.end(),
     [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
int count = 0, end = INT_MIN;
for (auto& iv : intervals) {
    if (iv[0] >= end) {          // 不重叠（端点相接算不重叠）
        ++count;
        end = iv[1];
    }
}
```

**为什么按右端点**：越早结束，给后面留的空间越大。按左端点排是经典错误（反例：`[1,100]` 和 `[2,3]`）。

### 2. 跳跃游戏（维护最远可达）

```cpp
int reach = 0;
for (int i = 0; i < (int)nums.size(); ++i) {
    if (i > reach) return false;         // 当前下标都到不了
    reach = max(reach, i + nums[i]);
}
return true;
```

「维护当前能到的最远位置」——不用关心具体怎么跳。

### 3. 分发糖果 / 左右各扫一遍

两边都有约束时，**先从左扫一遍满足左约束，再从右扫一遍满足右约束**，取 `max`。

```cpp
vector<int> c(n, 1);
for (int i = 1; i < n; ++i) if (r[i] > r[i-1]) c[i] = c[i-1] + 1;
for (int i = n - 2; i >= 0; --i) if (r[i] > r[i+1]) c[i] = max(c[i], c[i+1] + 1);
```

### 4. 排序 + 双指针 / 交换论证

- 每次取最大和最小配对（船载人、救生艇）。
- 按「性价比」排序后尽量取（分数背包；**0/1 背包不能贪心**）。

### 5. 反悔贪心（堆辅助）

贪心地选，但允许「后悔」——用堆存已选，发现更好的就替换。典型：会议室安排最多次数、股票买卖含手续费、完成任务的最大收益。

## 什么时候贪心会错（反例意识）

| 问题 | 贪心 | 正确 |
| --- | --- | --- |
| 0/1 背包 | 按单价排序 | DP |
| 找零（币值任意） | 每次用最大面额 | DP（除非币值有倍数关系） |
| 最短路径含负边 | 每次选最近 | Bellman-Ford |
| 区间调度按左端点 | 错的 | 按右端点 |

## 易错点

- 排序比较器写成 `return a[1] <= b[1];` → 相等时返回 true，`sort` 要求严格弱序，会 **RE / 死循环**。必须用 `<`。
- 排序 key 选错（区间题最常错）。
- 边界：`INT_MIN` / 初始 `end` 的选择；空输入。
- 贪心只适用于「无后效」的题；有后效就得 DP。
- 别把「证明不出来」当成「一定错」——先写个暴力对拍小数据，能过就上。
