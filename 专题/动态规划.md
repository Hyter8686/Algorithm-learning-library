# 动态规划

## 什么时候想到它（识别信号）

- 求**最值 / 方案数 / 是否可行**，且问题能拆成**重叠子问题**。
- 暴力搜索会重复计算同一状态（画出递归树能看到重复节点）。
- 有「前 i 个」「容量 j」「区间 [l,r]」这种天然的**阶段**。
- 当前决策只依赖前面若干状态（无后效性）。

反面信号：要输出**所有方案** → 回溯；局部最优能推全局 → 贪心。

## 五步法（每次照这个顺序想，别跳）

1. **状态定义**：`dp[i][j]` 代表什么？—— 一句话能说清，不含糊。
2. **转移方程**：`dp[i][j]` 从哪些旧状态来？
3. **初始化**：`dp[0]` / 第一行第一列是什么？
4. **遍历顺序**：保证用到的旧状态**已经算好**。
5. **答案**：`dp[n]` 还是 `*max_element(dp.begin(), dp.end())`？

90% 的 DP 卡住，卡在第 1 步和第 4 步。

## 一、线性 DP

```cpp
// 爬楼梯：dp[i] = dp[i-1] + dp[i-2]
vector<int> dp(n + 1, 0);
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; ++i) dp[i] = dp[i - 1] + dp[i - 2];
```

**空间压缩**：只依赖前两项 → 用两个变量滚动，O(1) 空间。凡是 `dp[i]` 只依赖 `dp[i-1]`，都可以压。

常见状态设计：

| 题 | 状态 |
| --- | --- |
| 打家劫舍 | `dp[i]` = 考虑前 i 间房的最大金额；`max(dp[i-1], dp[i-2] + a[i])` |
| 最长递增子序列 | `dp[i]` = **以 i 结尾**的 LIS 长度（不是前 i 个的答案！） |
| 最大子数组和 | `dp[i]` = 以 i 结尾的最大和 |
| 编辑距离 | `dp[i][j]` = word1 前 i 个变成 word2 前 j 个的最少操作 |

「以 i 结尾」和「前 i 个」是两种完全不同的状态，选错了转移就写不出来。

## 二、背包（必背）

### 01 背包：每个物品选 0 或 1 次

```cpp
vector<int> dp(cap + 1, 0);              // dp[j] = 容量 j 时的最大价值
for (auto& item : items) {
    int w = item[0], v = item[1];
    for (int j = cap; j >= w; --j)       // 倒序！保证每件只用一次
        dp[j] = max(dp[j], dp[j - w] + v);
}
```

**为什么倒序**：`dp[j-w]` 若是本轮刚更新的，就等于这件物品被用了多次（变成完全背包）。倒序读到的是上一轮的值。

### 完全背包：每个物品无限次

```cpp
for (auto& item : items) {
    int w = item[0], v = item[1];
    for (int j = w; j <= cap; ++j)       // 正序
        dp[j] = max(dp[j], dp[j - w] + v);
}
```

### 求「方案数」时，遍历顺序决定含义（重点）

```cpp
// 组合数（{1,2} 和 {2,1} 算一种）：物品在外，容量在内
for (int w : items)
    for (int j = w; j <= cap; ++j)
        dp[j] += dp[j - w];

// 排列数（顺序不同算不同）：容量在外，物品在内
for (int j = 0; j <= cap; ++j)
    for (int w : items)
        if (j >= w) dp[j] += dp[j - w];
```

这条规律几乎所有「零钱兑换 II / 组合总和 IV」的题都靠它，值得单独记。

### 背包的变形

- 恰好装满：`dp[0] = 0`，其余 `INT_MIN`（用 `-1e9` 更安全）；最后 `dp[cap] < 0` 说明无解。
- 至多 / 至少：至少型常要 `max(0, j - w)` 截断。
- 二维费用（两个容量）：多一维循环。
- **方案数用 `long long`**：力扣的计数题经常要求「结果对 1e9+7 取模」，用 int 中途就溢出了。

## 三、区间 DP

`dp[l][r]` 表示区间 `[l, r]` 的答案，按**区间长度从小到大**枚举：

```cpp
vector<vector<int>> dp(n, vector<int>(n, 0));
for (int len = 2; len <= n; ++len)
    for (int l = 0; l + len - 1 < n; ++l) {
        int r = l + len - 1;
        for (int k = l; k < r; ++k)          // 枚举分割点
            dp[l][r] = max(dp[l][r], dp[l][k] + dp[k+1][r] + cost(l, r, k));
    }
```

「必须按长度遍历」是因为 `dp[l][r]` 依赖更短的区间。典型：戳气球、矩阵链乘、最长回文子序列。

## 四、树形 DP / 状态压缩

- 树形：后序遍历，返回值是「子树的信息」；多状态时返回 `pair`/元组或二维 dp。
- 状压：n ≤ 20，用 `mask` 表示「哪些已选」，`dp[mask]` 转移时枚举下一个。

```cpp
for (int mask = 0; mask < (1 << n); ++mask)
    for (int i = 0; i < n; ++i)
        if (mask >> i & 1) { /* i 已在集合里 */ }
```

## 易错点

- **状态定义含糊**（「前 i 个的最优」到底含不含 i），导致转移写不出来。
- 01 背包写成正序 → 变成完全背包，答案偏大。
- 初始化漏了：求 min 时没初始化为 `INT_MAX`，求 max 时没初始化为 `INT_MIN`；**用 `INT_MIN` 做加法会溢出**，改用 `-1e9`。
- 遍历顺序与依赖方向不一致（二维里 `dp[i][j]` 依赖 `dp[i][j-1]` 就必须 j 内层正序）。
- 把「方案数」当「最值」写，`max` 和 `+` 混了。
- `vector<vector<int>> dp(n, vector<int>(m, 0))` 别写成 `vector<vector<int>> dp(n, m)`——第二个参数是元素类型，不是大小。
