# 排序

## 什么时候想到它（识别信号）

- 题目里出现「按……排序」「字典序最小」「相邻元素」「区间」。
- 贪心题的第一步几乎都是排序。
- 需要**顺序**才能用双指针 / 二分 / 去重。
- 求逆序对、第 k 小（`nth_element`）。

排序本身很少是答案，它通常是**让后续算法成立的前提**。

## 一、先记住 C++ 的现成工具

```cpp
sort(a.begin(), a.end());                              // 升序，O(n log n)，不稳定
sort(a.begin(), a.end(), greater<int>());              // 降序
stable_sort(a.begin(), a.end());                       // 稳定，O(n log^2 n) 或 O(n log n)
nth_element(a.begin(), a.begin() + k, a.end());        // 第 k 小放到 a[k]，O(n) 平均
reverse(a.begin(), a.end());
```

力扣上 99% 的题用 `sort` 就够。手写快排只在面试要求时写。

## 二、自定义比较器（最高频出错点）

```cpp
// 结构体：按分数降序，分数相同按名字升序
sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});

// pair：默认先比 first 再比 second
sort(v.begin(), v.end());   // vector<pair<int,int>> 天然可用
```

**比较器必须是严格弱序**：对任意 a，`cmp(a, a)` 必须为 false。所以：

- 能写 `<` 就写 `<`，**不要写 `<=`**。`return a.x <= b.x;` 会导致 `std::sort` 越界访问 → **RE**（debug 版会直接 assert 崩）。
- 相等情况要么在 if 里返回 false，要么交给第二个 key。

这和 Python 的 `key=` 完全不同——Python 里 `key=lambda x: x` 天然安全，C++ 的比较器是「小于」，写错就崩。

## 三、手写快排（要会）

```cpp
void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int i = l, j = r;
    int pivot = a[l + (r - l) / 2];       // 取中间值当基准，避免有序数组退化
    while (i <= j) {
        while (a[i] < pivot) ++i;
        while (a[j] > pivot) --j;
        if (i <= j) {
            swap(a[i], a[j]);
            ++i; --j;
        }
    }
    quickSort(a, l, j);
    quickSort(a, i, r);
}
```

要点：

- 基准取**中间**，不要取 `a[l]` —— 已排序数组会退化成 O(n²)（力扣有专门卡这点的用例）。
- 先内部 `++i` / `--j`，再交换，最后递归 `[l, j]` 和 `[i, r]`，这样天然处理了等于 pivot 的元素。
- 递归写错边界 → 死循环。

## 四、归并排序（要会，因为能求逆序对）

```cpp
long long mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return 0;
    int mid = l + (r - l) / 2;
    long long cnt = mergeSort(a, l, mid) + mergeSort(a, mid + 1, r);

    vector<int> tmp;
    tmp.reserve(r - l + 1);
    int i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp.push_back(a[i++]);
        else {
            cnt += mid - i + 1;           // a[i..mid] 都比 a[j] 大 → 逆序对
            tmp.push_back(a[j++]);
        }
    }
    while (i <= mid) tmp.push_back(a[i++]);
    while (j <= r)   tmp.push_back(a[j++]);
    for (int k = l; k <= r; ++k) a[k] = tmp[k - l];
    return cnt;
}
```

`cnt += mid - i + 1` 这一行是逆序对题的全部核心。**结果用 `long long`**（逆序对最多 n(n-1)/2，n = 10^5 时约 5×10^9，超 int）。

## 五、其他排序

| 算法 | 时间 | 特点 |
| --- | --- | --- |
| 快排 | 平均 O(n log n)，最坏 O(n²) | 原地、不稳定、常数小 |
| 归并 | O(n log n) | 稳定、需要 O(n) 额外空间、能求逆序对 |
| 堆排 | O(n log n) | 原地、不稳定、常数大 |
| 计数排序 | O(n + k) | 值域小时极快 |
| 桶排序 | O(n) 平均 | 分布均匀时 |

计数排序（值域 0~1000 之类）：

```cpp
vector<int> cnt(maxVal + 1, 0);
for (int x : a) ++cnt[x];
int p = 0;
for (int v = 0; v <= maxVal; ++v)
    while (cnt[v]--) a[p++] = v;
```

## 六、排序 + 其他套路

- **排序 + 双指针**（两数之和、三数之和、最接近的三数之和）。
- **排序 + 去重**：`sort` 后 `if (i && a[i] == a[i-1]) continue;`
- **排序 + 贪心**（区间调度按右端点、分发饼干按胃口）。
- **排序 + 二分**（找第一个 ≥ target）。
- **按自定义 key 排序**（把数字拼成最小数：`to_string(a) + to_string(b) < to_string(b) + to_string(a)`）。

## 易错点

- 比较器写 `<=` / `>=` → 严格弱序被破坏 → RE 或结果错乱。
- 比较器里捕获了会变的变量（比如 `sort` 过程中被修改）→ UB。
- 快排基准取首元素，遇到有序数据退化 O(n²)。
- 归并的 `tmp` 每次递归都新建 → 慢；可以开全局 `tmp` 数组复用。
- `sort` 不稳定：多关键字排序必须把第二个 key 写进比较器，不能指望原顺序保留。
- 排 `vector<pair<int,int>>` 想按 second 排 → 要自己写比较器。
- `nth_element` 之后数组是「k 左边都比它小，右边都比它大」，但两边**内部无序**。
