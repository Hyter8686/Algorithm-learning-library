# 回溯

## 什么时候想到它（识别信号）

- 求**所有方案**：所有组合、所有排列、所有划分、所有路径。
- 数据规模小（n ≤ 20 左右），指数级复杂度可接受。
- 每一步做选择，选了之后可能后悔 → 「撤销选择」。

关键词：**枚举所有可能**。如果要的是「最优值」而不是「所有方案」，先想 DP / 贪心。

## 核心思想

一棵**决策树**：每层决定「当前这一步选谁」，走到叶子就是一个完整方案。

```
void backtrack(路径, 选择列表) {
    if (满足结束条件) { 收集结果; return; }
    for (选择 : 选择列表) {
        if (不合法) continue;      // 剪枝
        做选择;
        backtrack(路径, 新选择列表);
        撤销选择;
    }
}
```

**递归前后对称**（`push_back` / `pop_back`），这是回溯唯一必须记死的事。

用 C++ 写回溯的通行做法：`path` 和 `res` 都是**成员变量**，递归函数只传「当前层的位置」。

```cpp
class Solution {
    vector<vector<int>> res;
    vector<int> path;
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        backtrack(0, nums);
        return res;
    }
    void backtrack(int start, vector<int>& nums) {
        res.push_back(path);                 // C++ 这里是值拷贝，天然安全
        for (int i = start; i < (int)nums.size(); ++i) {
            path.push_back(nums[i]);
            backtrack(i + 1, nums);
            path.pop_back();
        }
    }
};
```

好消息：C++ 的 `res.push_back(path)` 是**拷贝**，不会像 Python 那样所有结果指向同一个列表。代价是拷贝开销——数据量大时在递归入口 `res.reserve(...)` 一下。

## 三种基本型

### 组合（不考虑顺序，用 `start` 防重复）

```cpp
void backtrack(int start, vector<int>& nums) {
    res.push_back(path);                    // 每个节点都是解（子集型）
    for (int i = start; i < (int)nums.size(); ++i) {
        path.push_back(nums[i]);
        backtrack(i + 1, nums);             // i+1：同一个数不能重复用
        path.pop_back();
    }
}
```

- 元素可重复使用 → 传 `i`；不可重复 → 传 `i + 1`。
- 只取长度 k → 在 `if (path.size() == k)` 时收集并 `return`。

### 排列（考虑顺序，用 `used` 防重复）

```cpp
void backtrack(vector<int>& nums, vector<bool>& used) {
    if (path.size() == nums.size()) {
        res.push_back(path);
        return;
    }
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(nums[i]);
        backtrack(nums, used);
        path.pop_back();
        used[i] = false;
    }
}
```

`vector<bool>` 是特化的位压缩容器，单独用没问题；但**不要对它取引用后同时读写**，容易踩坑。介意的话用 `vector<char>`。

### 有重复元素的去重（排序 + 同层跳过）

```cpp
sort(nums.begin(), nums.end());
for (int i = start; i < (int)nums.size(); ++i) {
    if (i > start && nums[i] == nums[i - 1]) continue;   // 同一层用过相同的值，跳过
    ...
}
```

`i > start` 表示「同层」，不是「同一分支」。这一句是 40 题和 90 题的全部难点。

## 剪枝

- 排序后，`if (当前和 > target) break;`（后面的更大，不可能满足）。
- 剩余元素不够凑满 k 个 → `break`。
- 组合总和里 `if (sum > target) return;`。

剪枝不是优化，是能不能过的时间分界线。

## 易错点

- 撤销选择漏写，或写在了 `continue` 之前。
- 组合用 `start`、排列用 `used`，两者混用会重复或漏解。
- 去重时把 `i > start` 写成 `i > 0`，会把「不同层但同值」的合法方案也砍掉。
- `path` 按值传参（`vector<int> path`）而不是成员变量/引用 → 每层拷贝，慢到超时。
- `nums` 参数传值而不是 `vector<int>&`，同理。
- 递归深度大时注意栈；`res` 结果集特别大时先 `res.reserve()`。
