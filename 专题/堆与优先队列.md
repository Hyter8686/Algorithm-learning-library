# 堆与优先队列

## 什么时候想到它（识别信号）

- 要**动态地反复取最值**（每次都取最大/最小，同时还有新元素进来）。
- 「前 K 大 / 前 K 小 / 第 K 大」。
- 数据流的中位数、任务调度、合并 K 个有序序列。
- Dijkstra 里取当前距离最小的点。

C++ 的「堆」就是 `std::priority_queue`，**没有 `heapq` 那种直接对 vector 操作的接口**（虽然有 `make_heap`/`push_heap`/`pop_heap`，但日常用不到）。

## 核心思想

堆是一棵**完全二叉树**，只保证堆顶是极值，不保证整体有序。插入/删除 O(log n)，取顶 O(1)。

代价：**不能遍历、不能删除任意元素、不能查第 k 个**。需要这些就别用堆。

## 一、priority_queue 的三种基本形态

```cpp
// 大顶堆（默认）
priority_queue<int> maxHeap;

// 小顶堆
priority_queue<int, vector<int>, greater<int>> minHeap;

// pair 堆：默认按 first 比，再按 second 比
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;  // 小顶堆（按 first）
```

这三个模板参数必须写全（除了 C++14 起 `greater<>` 可以省略类型）。**默认是大顶堆，这是最坑的一点**——想取最小值一定要显式写 `greater<>`。

## 二、自定义比较器（最容易写反）

```cpp
struct Node { int val, id; };

struct Cmp {
    bool operator()(const Node& a, const Node& b) const {
        return a.val > b.val;      // 注意：'>' 得到的是小顶堆！
    }
};
priority_queue<Node, vector<Node>, Cmp> pq;
```

**逻辑是反的**：`operator()` 返回 true 表示「a 排在 b 后面（优先级更低）」。想要小顶堆就写 `a.val > b.val`。

记法：把它当成 `sort` 的比较器反过来用。`sort` 里写 `a < b` 是升序，堆里写 `a > b` 才是小顶堆。

lambda 也可以，但要 `decltype`：

```cpp
auto cmp = [](const Node& a, const Node& b) { return a.val > b.val; };
priority_queue<Node, vector<Node>, decltype(cmp)> pq(cmp);
```

## 三、常用接口

```cpp
pq.push(x);          // O(log n)
pq.top();            // O(1)，返回 const 引用，不能改
pq.pop();            // O(log n)，返回 void！要先 top 再 pop
pq.empty(); pq.size();
```

`pop()` 不返回值 —— 和 `stack`、`queue` 一样，别写 `int x = pq.pop();`。

## 四、经典套路

### 1. 前 K 大 → 维护大小为 k 的**小顶堆**

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
for (int x : nums) {
    pq.push(x);
    if ((int)pq.size() > k) pq.pop();   // 弹掉当前最小的
}
return pq.top();                         // 第 k 大
```

**反直觉但正确**：求前 K 大用小顶堆。因为要淘汰的是「最小的那些」，堆顶必须是最小值。时间复杂度 O(n log k)，空间 O(k)。

求前 K 小则反过来用大顶堆（默认那个）。

### 2. 数据流的中位数 → 两个堆

- 大顶堆存**较小的一半**，小顶堆存**较大的一半**。
- 保证 `maxHeap.size() == minHeap.size()` 或 `maxHeap.size() == minHeap.size() + 1`。
- 中位数：相等时取两顶平均，否则取大顶堆顶。

```cpp
priority_queue<int> lo;                                  // 大顶堆
priority_queue<int, vector<int>, greater<int>> hi;       // 小顶堆

void add(int x) {
    lo.push(x);
    hi.push(lo.top()); lo.pop();                         // 先过一遍保证有序
    if (hi.size() > lo.size()) { lo.push(hi.top()); hi.pop(); }
}
double median() {
    return lo.size() > hi.size() ? lo.top() : (lo.top() + hi.top()) / 2.0;
}
```

### 3. 合并 K 个有序链表/数组

把每个序列的「头」放进小顶堆，每次弹最小的，再把它的下一个推进去。

### 4. 任务调度 / 贪心 + 堆

「反悔贪心」：先贪心选，堆里存已选，发现更优就 pop 掉最差的换新的。

## 五、什么时候不该用堆

- 只需要一次最值 → `sort` 或 `max_element`。
- 需要删除任意元素 / 修改元素 → 用 `multiset`（`begin()`/`rbegin()` 取最值，`erase(iterator)` O(log n)）。
- 需要「取最值 + 判存在」→ `set` / `map`。

`multiset` 是堆的强力替代，尤其是要删指定元素时：

```cpp
multiset<int> s;
s.insert(x);
int mx = *s.rbegin(), mn = *s.begin();
s.erase(s.find(x));      // 按值删：erase(x) 会删掉所有等于 x 的
```

## 易错点

- 忘了默认是大顶堆，求最小值写成了 `priority_queue<int>`。
- 自定义比较器方向写反（返回 true 的那个「优先级更低」）。
- `pop()` 不返回值。
- `top()` 返回 const 引用，想改元素只能 pop 出来改再 push。
- 堆里存 `pair` 时忘了会先比 first；存指针/迭代器要注意比较的是地址还是值。
- 前 K 大用了大顶堆 → 复杂度退化成 O(n log n) 且要额外空间存全部元素。
- `priority_queue` 没有迭代器，不能 `for (auto x : pq)`。
