# 字符串

## 什么时候想到它（识别信号）

- 输入是字符串，问「子串 / 子序列 / 回文 / 异位词 / 编辑」。
- 需要**按字符计数**（异位词、字母异位、字符集有限）→ 数组当哈希。
- 需要「原地修改 / 双指针」→ C++ 的 `std::string` 是**可变的**，这点比 Python 方便得多。

C++ 的字符串题有三类核心工具：**双指针、计数数组、`substr`/`find`**。真正上 KMP 的题不多。

## 一、C++ string 的基本操作

```cpp
string s = "abc";
int n = (int)s.size();          // 注意强制转换，见下方坑
s[0] = 'x';                     // 可变，可以直接改
s.push_back('d'); s.pop_back();
s.substr(1, 2);                 // 从 1 开始取 2 个 → "bc"（第二个参数是长度！）
s.find("bc");                   // 返回 size_t，找不到是 string::npos
s.find('b', 2);                 // 从下标 2 开始找
s.rfind("ab");                  // 从后往前找
reverse(s.begin(), s.end());
s += "def";
to_string(123);                 // int → string
stoi("123"); stol("123");       // string → 数字（会抛异常）
```

**`substr(pos, len)` 第二个参数是长度，不是结束下标** —— 这是从 Python 切片 `s[1:3]` 转过来最容易错的地方。

判空用 `s.empty()`，别用 `s.size() == 0`。

## 二、按字符计数（最常用的套路）

字符集有限时，`int cnt[26]` / `int cnt[128]` 比 `unordered_map` 快得多：

```cpp
int cnt[26] = {0};
for (char c : s) ++cnt[c - 'a'];
```

- 只含小写字母 → `cnt[26]`，下标 `c - 'a'`。
- 含大小写、数字、符号 → `cnt[128]`，下标直接用 `(unsigned char)c`。
- 异位词：两个字符串的计数数组相等；或一个加、一个减，最后全 0。

## 三、双指针

### 反转 / 原地修改

```cpp
int l = 0, r = (int)s.size() - 1;
while (l < r) swap(s[l++], s[r--]);
```

### 反转字符串中的单词

先整体反转，再逐个单词反转；或用 `stringstream` 切词再拼。

```cpp
stringstream ss(s);
string w, res;
while (ss >> w) res = w + (res.empty() ? "" : " " + res);
```

### 判断回文

```cpp
int l = 0, r = (int)s.size() - 1;
while (l < r) {
    if (s[l] != s[r]) return false;
    ++l; --r;
}
```

带过滤版（只留字母数字并忽略大小写）用 `isalnum` + `tolower`。

## 四、字符分类函数（要 `<cctype>`）

```cpp
isalpha(c); isdigit(c); isalnum(c); isspace(c);
tolower(c); toupper(c);
```

**坑**：这些函数的参数是 `int`，传**负的 char**（比如 UTF-8 中文字节）是 UB。安全写法：`tolower((unsigned char)c)`。

## 五、子串查找与匹配

### 暴力 / `find`

```cpp
size_t pos = s.find(t);
while (pos != string::npos) {
    // 命中
    pos = s.find(t, pos + 1);
}
```

`find` 的平均复杂度不错，绝大多数题够用。

### KMP（要会原理，能手写）

`s[i]` 不匹配时，模式串指针 `j` 回退到 `next[j-1]`，而不是回到 0。

```cpp
vector<int> buildNext(const string& p) {
    int m = (int)p.size();
    vector<int> nxt(m, 0);
    int j = 0;
    for (int i = 1; i < m; ++i) {
        while (j > 0 && p[i] != p[j]) j = nxt[j - 1];
        if (p[i] == p[j]) ++j;
        nxt[i] = j;
    }
    return nxt;
}

int kmp(const string& s, const string& p) {
    auto nxt = buildNext(p);
    int j = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        while (j > 0 && s[i] != p[j]) j = nxt[j - 1];
        if (s[i] == p[j]) ++j;
        if (j == (int)p.size()) return i - j + 1;   // 首次出现位置
    }
    return -1;
}
```

`next[i]` 的含义：`p[0..i]` 的**最长相等前后缀长度**。手写容易错在 `j = nxt[j-1]` 写成 `j = nxt[j]`。

## 六、字符串哈希

判断「子串是否出现过 / 是否相等」时，滚动哈希 O(1) 取子串哈希：

```cpp
using ull = unsigned long long;
const ull BASE = 131;
vector<ull> h(n + 1, 0), pw(n + 1, 1);
for (int i = 0; i < n; ++i) {
    h[i + 1] = h[i] * BASE + (unsigned char)s[i];
    pw[i + 1] = pw[i] * BASE;
}
// 子串 [l, r] 的哈希：h[r+1] - h[l] * pw[r-l+1]
```

用 `unsigned long long` 让它自然溢出，等于 mod 2^64，写起来最省事（有碰撞概率，但竞赛/面试一般能过）。

## 七、C++ 特有的坑（重点）

1. **`s.size()` 返回 `size_t`（无符号）**。`for (int i = 0; i < s.size() - 1; ++i)` 在 `s` 为空时 `s.size() - 1` 变成巨大正数 → 越界 or 死循环。写法：`int n = (int)s.size();` 之后全用 `n`。
2. **`substr` 越界会抛 `out_of_range`**（不是返回空），力扣上直接 RE。
3. **`s[i]` 不检查边界**，越界是 UB（不像 Python 抛 IndexError）。
4. `s.find(...)` 返回 `size_t`，和 `-1` 比较**永远为假**，必须用 `string::npos`。
5. `char` 在某些平台上是有符号的，超过 127 的字节是负数 → `isalpha`/`tolower` 前转 `unsigned char`。
6. `"abc"` 是 `const char*`，和 `std::string` 混用时注意 `+` 的结合顺序（`"a" + s` 编译不过，得 `string("a") + s`）。
