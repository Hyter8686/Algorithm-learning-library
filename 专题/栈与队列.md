# 栈与队列

## 什么时候想到它（识别信号）

- **括号匹配 / 嵌套结构 / 最近一次未处理** → 栈。
- 求**「下一个更大/更小的元素」**、柱状图最大矩形、接雨水 → 单调栈。
- 求**滑动窗口最值** → 单调队列。
- BFS 层序、最短步数 → 队列。
- 表达式求值、字符串解码、路径简化 → 栈。

## 一、普通栈

```cpp
stack<int> st;
st.push(x);
st.pop();          // 注意：返回 void，不返回值！
st.top();          // 取栈顶要单独调
st.empty();
st.size();
```

**C++ 新手第一个大坑**：`int x = st.pop();` 编译不过。想「弹出并取回」要么先 `top()` 再 `pop()`，要么自己用 `vector`：

```cpp
vector<int> st;
st.push_back(x);
st.back();         // 栈顶
st.pop_back();     // 弹出
```

`vector` 当栈更快、能用下标访问、能直接遍历，日常刷题优先用它。

典型：有效括号、最小栈（辅助栈存当前最小值）、字符串解码（`"3[a2[c]]"`）、简化路径。

**递归的本质就是栈**，所以「用栈模拟递归」= 手动维护调用栈。

## 二、单调栈（重点）

问题形状：对每个 `i`，找左边/右边**第一个**比它大（或小）的元素。

```cpp
// 下一个更大元素：栈里存下标，栈内值单调递减
vector<int> nextGreater(vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> ans(n, -1), st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && nums[st.back()] < nums[i]) {
            ans[st.back()] = nums[i];   // i 就是 st.back() 右边第一个更大的
            st.pop_back();
        }
        st.push_back(i);
    }
    return ans;
}
```

**核心理解**：栈里维护的是「还没找到答案的候选」，它们的高度单调。新元素进来时，把所有比它矮的候选一次性结算掉——每个元素进栈出栈各一次，O(n)。

变体：

| 问法 | 改哪里 |
| --- | --- |
| 下一个更小 | `<` 改成 `>` |
| 左边第一个更大 | 从右往左遍历，或正序遍历时用「栈底方向」结算 |
| 循环数组 | 遍历两遍（`i % n`），或数组翻倍 |
| 柱状图最大矩形 | 对每根柱子求「左右第一个更矮的」，算宽度 = 右 - 左 - 1 |
| 接雨水 | 单调栈按「层」算水量 |

**哨兵技巧**：在数组首尾各加一个 0 或 `INT_MAX`，可以省掉「栈空了怎么办」和「最后栈里剩下的怎么结算」两处特判。

## 三、单调队列（滑动窗口最值）

```cpp
deque<int> dq;                     // 存下标，队首是当前窗口最大值
for (int i = 0; i < n; ++i) {
    while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();  // 队尾比新元素小的全踢掉
    dq.push_back(i);
    if (dq.front() <= i - k) dq.pop_front();                          // 队首过期
    if (i >= k - 1) ans.push_back(nums[dq.front()]);
}
```

## 四、队列 / 双端队列

```cpp
queue<int> q;          // push / pop / front / back，pop 同样不返回值
deque<int> dq;         // push_front / pop_front / push_back / pop_back，O(1)
```

- BFS 用 `queue` 或 `deque`；**不要用 `vector` 当队列**（`erase(begin())` 是 O(n)）。
- 需要两端操作（回文检查、0-1 BFS）用 `deque`。
- **`queue` / `stack` 的 `pop()` 都不返回值**，而且都不支持迭代器；要遍历就得自己用 `deque` / `vector`。

## 易错点

- `st.pop()` 返回 `void`，先 `top()` 再 `pop()`。
- 单调栈**存下标还是存值**：要算宽度/距离就必须存下标。
- 处理「相等」时用 `<` 还是 `<=` 会影响是否保留重复元素，柱状图题里会导致宽度算错。
- 单调队列**先踢队尾、再加入、最后判队首过期**，顺序错了会留下过期元素。
- 用 `deque` 的 `pop_back()` 前没判 `empty()`，空容器 pop 是 UB。
- `stack` 默认底层是 `deque`；如果栈很小，`stack<int, vector<int>>` 更快。
