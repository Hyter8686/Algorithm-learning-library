# 二分查找

## 什么时候想到它（识别信号）

- 数组**有序**（或局部有序、旋转有序），要求在 O(log n) 内查找。
- 求「**最小化最大值 / 最大化最小值**」——看到这两个词基本就是二分答案。
- 答案具有**单调性**：`check(x)` 为真之后一直为真（或一直为假）。这是二分答案的充分条件。
- 「第 k 小」「分割数组使……最小」这类。

## 核心思想

每次排除一半。所有二分题的混乱都来自**区间定义不统一**——所以先选一种写法，然后**永远只写这一种**。

## 一、区间写法（推荐：[lo, hi) 左闭右开）

求**第一个 ≥ target** 的下标（即 `lower_bound`）：

```cpp
int lowerBound(vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size();        // [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;       // 防溢出
        if (a[mid] < target) lo = mid + 1;
        else                 hi = mid;
    }
    return lo;                              // 可能等于 n（target 比所有元素大）
}
```

求**第一个 > target**（`upper_bound`）：把 `<` 改成 `<=`。

- `lower_bound` 结果 = target 第一次出现的位置 = 小于 target 的元素个数。
- 区间内元素个数 = `upper_bound - lower_bound`。

`mid` 写 `lo + (hi - lo) / 2` 而不是 `(lo + hi) / 2`：`lo + hi` 在极端情况下会 int 溢出。

## 二、双闭区间写法 [lo, hi]

也是对的，但要配套改：

```cpp
int lo = 0, hi = (int)a.size() - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == target) return mid;
    else if (a[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}
return -1;
```

**两套写法不能混**：`while (lo <= hi)` 配 `hi = mid` 会死循环，`while (lo < hi)` 配 `hi = mid - 1` 会漏答案。这是我踩过的头号坑。

## 三、std::lower_bound / upper_bound

```cpp
auto it = lower_bound(a.begin(), a.end(), target);
if (it != a.end() && *it == target) { /* 找到 */ }
int idx = (int)(it - a.begin());
```

- 要求区间**已按 `<` 排好序**（或传入自定义比较器）。
- 自定义结构体要能比较，或者传 lambda 作第三个参数。
- `set` / `map` 用成员函数 `s.lower_bound(x)`（O(log n)），别用 `std::lower_bound(s.begin(), s.end(), x)`（那是 O(n)）。

## 四、二分答案（模板题级别的重要）

**把「求最优值」转成「判定这个值行不行」**：

```cpp
// 求最小的 x，使 check(x) 为真；check 单调：真之后一直真
int lo = minPossible, hi = maxPossible;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;          // 注意：这里用下取整
    if (check(mid)) hi = mid;              // mid 可行 → 答案在左半边（含 mid）
    else            lo = mid + 1;
}
return lo;
```

求「最大的 x 使 check 为真」时反过来：`if (check(mid)) lo = mid; else hi = mid - 1;`，并且 `mid = lo + (hi - lo + 1) / 2`（**上取整**，否则死循环）。

记法：**可行就保留 mid 的那一侧，取整方向要朝着「保留 mid」的那边**。

判断能不能二分答案的三个条件：

1. 答案是一个范围里的整数/浮点数（有上下界）。
2. 有 `check(x)` 判定函数。
3. `check` 单调。

典型：爱吃香蕉的珂珂（速度）、分割数组的最大值（子数组和上限）、在 D 天内送达包裹（船载重量）。

浮点二分：固定循环 100 次，比 `while (hi - lo > 1e-9)` 稳。

## 易错点

- 两套区间写法混用 → 死循环或漏解（最高频）。
- `mid` 用 `(lo + hi) / 2` 溢出。
- `hi` 初始值取 `n` 还是 `n - 1`，跟区间开闭必须一致。
- 求「第一个满足条件」时返回值可能越界（`== n`），要判。
- 二分答案的 `check` 里自己写错（比如用 int 累加溢出）→ 用 `long long`。
- 旋转数组：先判断哪半边有序，再决定往哪边收缩；有重复元素时最坏退化成 O(n)。
- 有重复元素求「第一个/最后一个」位置，用 lower/upper_bound 组合，别自己写等号判断。
