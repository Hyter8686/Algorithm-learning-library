# 数组与双指针

## 什么时候想到它（识别信号）

- 数组**有序**，要找一对数 / 一个区间 → 对撞指针。
- 要求**原地**修改、O(1) 额外空间（删除元素、去重、移动零）。
- 链表/数组里找**环**、找**中点**、找**倒数第 k 个** → 快慢指针。
- 两个有序序列要合并 / 求交集 → 分离双指针。

一句话：双指针的本质是**用单调性砍掉不可能的分支**，把 O(n²) 的枚举压成 O(n)。

## 套路

### 1. 对撞指针（left 从左、right 从右，向中间收）

前提：数组有序，或者「两端往里」能保证不丢解（如接雨水、盛最多水）。

```cpp
int l = 0, r = (int)a.size() - 1;
while (l < r) {
    long long s = (long long)a[l] + a[r];   // 防 int 溢出
    if (s == target) return {l, r};
    else if (s < target) ++l;               // 和太小，只能让小的变大
    else --r;                               // 和太大，只能让大的变小
}
```

**为什么不会漏解**：当 `a[l] + a[r] < target` 时，`a[l]` 配任何 `<= a[r]` 的数都太小，所以 `l` 这一整行可以整体排除。

### 2. 快慢指针

```cpp
ListNode *slow = head, *fast = head;
while (fast && fast->next) {
    slow = slow->next;            // fast 到终点时 slow 在中点
    fast = fast->next->next;
}
```

用途：判环（相遇即有环）、找环入口（相遇后一个指针回到 head，同速前进再相遇处即入口）、找中点、删除倒数第 n 个（先让 fast 走 n 步）。

### 3. 同向双指针 / 读写指针（原地删除类）

```cpp
int write = 0;
for (int read = 0; read < (int)a.size(); ++read)
    if (keep(a[read])) a[write++] = a[read];
// 前 write 个就是结果
```

传参记得是 `vector<int>& a`（引用），值传递改不动原数组——这是 C++ 最容易犯的低级错。

## 易错点

- `while (l < r)` 还是 `l <= r`：找一对数用 `<`（不能自己配自己）；二分/单元素场景才用 `<=`。
- **`int` 溢出**：`a[l] + a[r]` 在 10^9 量级会爆 int，题解里大量「两数/三数之和」的 WA 都是这个原因，习惯性转 `long long` 或先减后比。
- 对撞指针**必须先排序**，除非题目本身保证单调；排序会丢原下标，需要额外记录。
- 去重（三数之和）：固定第一个数后，`l`、`r` 跳过相同值要在**找到一个解之后**跳，位置写错会漏解。
- 移动零 / 移除元素这类题传的是引用，别不小心把 `a` 拷了一份。
