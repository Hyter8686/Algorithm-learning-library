# 位运算

## 什么时候想到它（识别信号）

- 数据范围写着「每个元素出现两次/三次，只有一个出现一次」。
- 要求 **O(1) 额外空间**。
- 出现「子集」「状态压缩」「集合」的表示，n ≤ 20。
- 求「二进制中 1 的个数」「是否是 2 的幂」「最低位的 1」。

## 一、六个基本运算（必须条件反射）

| 运算 | 写法 | 用途 |
| --- | --- | --- |
| 与 | `a & b` | 取某位、判奇偶（`x & 1`） |
| 或 | `a \| b` | 置 1 |
| 异或 | `a ^ b` | 翻转位、找单个数字 |
| 取反 | `~a` | 注意结果含符号位 |
| 左移 | `a << k` | 乘 2^k |
| 右移 | `a >> k` | 除 2^k（**有符号数是算术右移，高位补符号位**） |

## 二、常用位技巧（背下来）

```cpp
x & 1                 // 奇偶
x & (x - 1)           // 去掉最低位的 1（Brian Kernighan 数 1 的个数）
x & (-x)              // 最低位的 1（lowbit）
x | (1 << k)          // 把第 k 位置 1
x & ~(1 << k)         // 把第 k 位置 0
x ^ (1 << k)          // 翻转第 k 位
(x >> k) & 1          // 取第 k 位
x & (x - 1) == 0      // 是否是 2 的幂（x > 0）
a ^ a == 0            // 自己异或自己为 0
```

数 1 的个数：

```cpp
int count = 0;
while (x) { x &= x - 1; ++count; }     // 每次消掉一个 1
// 或者直接用 GCC 内置：
__builtin_popcount(x);                  // int 版
__builtin_popcountll(x);                // long long 版
__builtin_ctz(x);                       // 末尾 0 的个数
__builtin_clz(x);                       // 前导 0 的个数（x 不能为 0）
```

力扣用的 GCC 支持这些内置函数，放心用。

## 三、异或的三大性质

1. `a ^ a = 0`，`a ^ 0 = a` —— 相同的抵消。
2. 异或满足交换律、结合律 —— **顺序无关**，这是它能解题的根本。
3. `a ^ b ^ a = b`。

### 只出现一次的数字

```cpp
int ans = 0;
for (int x : nums) ans ^= x;
return ans;
```

所有出现两次的都抵消，剩下那个。**不需要哈希表，O(1) 空间**。

### 只出现一次的数字 II（其余出现三次）

按位统计：每一位上 1 的个数模 3，就是答案那一位。

```cpp
int ans = 0;
for (int k = 0; k < 32; ++k) {
    int cnt = 0;
    for (int x : nums) cnt += (x >> k) & 1;
    if (cnt % 3) ans |= 1 << k;
}
```

### 只出现一次的两个数字

全部异或得到 `a ^ b`，取其中最低位的 1 作为分组依据，把数组分成两组分别异或。

```cpp
int x = 0;
for (int v : nums) x ^= v;
int low = x & (-x);                    // 找出 a、b 不同的那一位
int a = 0, b = 0;
for (int v : nums) (v & low) ? a ^= v : b ^= v;
return {a, b};
```

## 四、状态压缩（子集枚举）

n ≤ 20 时，用一个 int 表示「选了哪些」：

```cpp
for (int mask = 0; mask < (1 << n); ++mask) {
    for (int i = 0; i < n; ++i)
        if (mask >> i & 1) { /* i 在集合中 */ }
}

// 枚举 mask 的所有子集（总复杂度 3^n）
for (int sub = mask; sub; sub = (sub - 1) & mask) { /* ... */ }
```

`(1 << n)` 当 n = 31 时是未定义行为（`1` 是有符号 int，`1 << 31` 溢出），要写 `1LL << n`。这是 C++ 特有的坑，Python 没有。

## 五、C++ 的符号与溢出坑（重点）

- **`int` 是有符号的，负数用补码**。`~0 == -1`，不是 `0xFFFFFFFF` 那个正数。
- `1 << 31` 是 **UB**（有符号溢出）。要写 `1u << 31` 或 `1LL << 31`。
- `-1 >> 1 == -1`（算术右移，高位补 1）。想逻辑右移要转 `unsigned`。
- `x & (-x)` 在 `x == INT_MIN` 时溢出（`-INT_MIN` 还是 `INT_MIN`）—— 少见但要知道。
- 位运算优先级**低于** `==`、`<`：`if (x & 1 == 0)` 实际是 `x & (1 == 0)`，**必须加括号** `if ((x & 1) == 0)`。
- `long long` 的位运算别忘了 `1LL`，光写 `1 << i` 还是 int。

## 六、其他常见题

- 汉明距离：`__builtin_popcount(a ^ b)`。
- 颠倒二进制位：循环 32 次，`res = (res << 1) | (n & 1); n >>= 1;`（用 `uint32_t`）。
- 两数之和不用加号：`while (b) { carry = (a & b) << 1; a ^= b; b = carry; }`。
- 格雷编码：`i ^ (i >> 1)`。

## 易错点

- 优先级：位运算比比较运算符低，**一律加括号**。
- `1 << 31` / `1 << 63` 溢出 → 用 `1LL` 或 `1u`。
- 负数右移是算术右移，`-1 >> 1` 还是 `-1`；统计位时用 `unsigned` 或无符号类型。
- `x & (x-1)` 判 2 的幂时忘了排除 `x <= 0`。
- 循环里 `1 << i` 的 `i` 超过 30 时结果错乱。
- 异或题里有「出现三次」的，不能直接 `^`，要按位统计。
