# 图论

## 什么时候想到它（识别信号）

- 题目里有**节点 + 边**的显式描述；或者隐含的「状态之间能互相到达」（单词接龙、课程先修、迷宫）。
- 问「能否到达 / 有几条路 / 最少几步 / 最早什么时候完成 / 是否成环」。
- 网格题（岛屿、迷宫）本质是图，四方向 BFS/DFS。

先问自己三个问题：**有向还是无向？有权还是无权？有没有环？**

## 一、建图

邻接表是默认选择（`vector<vector<int>>`），邻接矩阵只在 n ≤ 500 且需要频繁判边时用。

```cpp
int n = ...;
vector<vector<int>> g(n);                 // 邻接表
for (auto& e : edges) {
    int u = e[0], v = e[1];
    g[u].push_back(v);
    g[v].push_back(u);                    // 无向图才加这行
}

// 带权：vector<vector<pair<int,int>>> g(n);  g[u].push_back({v, w});
```

## 二、遍历：DFS 与 BFS

```cpp
vector<bool> vis(n, false);

// DFS
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u]) if (!vis[v]) dfs(v);
}

// BFS
queue<int> q;
q.push(src); vis[src] = true;
int step = 0;
while (!q.empty()) {
    int sz = q.size();
    for (int i = 0; i < sz; ++i) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (vis[v]) continue;
            vis[v] = true;                 // 入队时就标记，不要出队才标
            q.push(v);
        }
    }
    ++step;
}
```

**无权图最短路径 = BFS**；DFS 求的不是最短。

C++ 递归 DFS 在 n = 10^5 的链状图上会爆栈，改显式栈或 BFS。

## 三、拓扑排序（有向无环图）

```cpp
vector<int> indeg(n, 0);
for (int u = 0; u < n; ++u) for (int v : g[u]) ++indeg[v];

queue<int> q;
for (int i = 0; i < n; ++i) if (indeg[i] == 0) q.push(i);

vector<int> order;
while (!q.empty()) {
    int u = q.front(); q.pop();
    order.push_back(u);
    for (int v : g[u]) if (--indeg[v] == 0) q.push(v);
}
// order.size() < n → 有环
```

用途：课程表（能否修完）、依赖排序。判环也可以 DFS 三色标记（0 未访问 / 1 访问中 / 2 完成，遇到 1 就有环）。

## 四、并查集（无向图连通性、判环）

```cpp
class DSU {
    vector<int> p;
public:
    DSU(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;          // 已经在同一集合 → 这条边构成环
        p[a] = b;
        return true;
    }
};
```

`p[x] = find(p[x])` 是路径压缩，一行就够（不写按秩合并也接近常数）。
**加边时用 `unite` 的返回值判环** —— 无向图判「多余的边」「最小生成树」全靠这个。

## 五、最短路

### Dijkstra（非负权，单源）

```cpp
vector<long long> dist(n, LLONG_MAX);
priority_queue<pair<long long,int>, vector<pair<long long,int>>, greater<>> pq;
dist[src] = 0;
pq.push({0, src});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;             // 懒删除：过期状态直接跳过
    for (auto& [v, w] : g[u]) {
        if (d + w < dist[v]) {
            dist[v] = d + w;
            pq.push({dist[v], v});
        }
    }
}
```

- **priority_queue 默认是大顶堆**，所以要 `greater<>` + `pair` 才能当小顶堆用（`greater<>` 要加 `<functional>`，力扣一般已包含）。
- `pair` 默认先比 first，正好是距离。
- 不能处理负权边（要 Bellman-Ford / SPFA）。

### Bellman-Ford（含负权）

对所有边松弛 n-1 轮；再松弛一轮还能变短 → 有负环。

### Floyd（多源，n ≤ 400）

`for k for i for j: d[i][j] = min(d[i][j], d[i][k] + d[k][j]);` —— **k 必须放最外层**。

## 六、网格图

- 方向数组：`int dir[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};`
- 边界检查：`0 <= nr && nr < m && 0 <= nc && nc < n`
- 可以原地把访问过的格子改成 `'0'` / 特殊值，省一个 `vis` 数组。

## 易错点

- BFS 出队时才标记访问 → 同一节点被重复入队，复杂度爆炸。**入队时标记**。
- `dist` 用 `INT_MAX` 做加法会溢出 → 用 `LLONG_MAX` 或先判 `d > dist[u]` 跳过。
- 拓扑排序忘了先统计入度，或者有环时没检查 `order.size() == n`。
- 并查集 `find` 忘了路径压缩，退化到 O(n)。
- 无向图建边只加了一个方向。
- 网格题的「方向数组 + 边界判断」里把 `m`（行）和 `n`（列）写反。
- `vector<vector<int>> g(n)` 比 `vector<vector<int>> g(n, vector<int>())` 简洁，两者等价。
