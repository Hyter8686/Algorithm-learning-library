# 前缀和与差分

## 什么时候想到它（识别信号）

- 反复查询**区间和 / 区间计数**，且数组不变 → 前缀和。
- 数**有多少个子数组满足「和 = k」** → 前缀和 + 哈希表（最容易被忽略的一类）。
- 对区间做**大量整体加减**，最后才问一次结果 → 差分。
- 二维矩阵的矩形区域和 → 二维前缀和。

前缀和把「区间」变成「两个点之差」，这是它唯一但极强的价值。

## 前缀和

```cpp
vector<long long> pref(n + 1, 0);        // pref[i] = a[0..i-1] 的和
for (int i = 0; i < n; ++i) pref[i + 1] = pref[i] + a[i];

long long sum = pref[r + 1] - pref[l];   // 区间 [l, r] 闭区间
```

`pref[0] = 0` 这个哨兵不是装饰：没有它，「从下标 0 开始的子数组」要单独特判。
**类型必须是 `long long`**：10^5 个 10^9 的和会超 int32。

### 前缀和 + 哈希表：和为 k 的子数组

```cpp
unordered_map<long long, int> cnt;
cnt[0] = 1;                 // 空前缀出现一次
long long cur = 0;
int ans = 0;
for (int x : a) {
    cur += x;
    auto it = cnt.find(cur - k);
    if (it != cnt.end()) ans += it->second;   // 之前有多少个前缀和 = cur-k
    ++cnt[cur];
}
```

注意 `cnt[0] = 1` 的含义：`cur == k` 时，`cur - k == 0`，靠它统计到「从头开始的整个子数组」。

### 二维前缀和

```cpp
vector<vector<long long>> pref(n + 1, vector<long long>(m + 1, 0));
for (int i = 0; i < n; ++i)
    for (int j = 0; j < m; ++j)
        pref[i+1][j+1] = a[i][j] + pref[i][j+1] + pref[i+1][j] - pref[i][j];

// 子矩阵 (r1,c1)..(r2,c2) 含端点
long long S = pref[r2+1][c2+1] - pref[r1][c2+1] - pref[r2+1][c1] + pref[r1][c1];
```

二维数组注意**内存布局**：`pref[i][j]` 按行连续，`i` 的最内层循环写错会导致 cache miss，但正确性优先。

### 前缀和 + 二分：让前缀和「制造单调性」

前缀和的第二个身份不是「省计算」，而是**把「选前 k 个的和」变成一个可以直接二分的递增数组**。

```cpp
sort(a.begin(), a.end());                  // 子序列题：先排序，贪心选最小的
vector<long long> pref(n + 1, 0);          // pref[k] = 前 k 个最小元素之和
for (int i = 0; i < n; ++i) pref[i + 1] = pref[i] + a[i];

// 问「和 <= q 最多能选几个」→ pref 递增，找最后一个 <= q 的位置
int k = (int)(upper_bound(pref.begin(), pref.end(), (long long)q) - pref.begin()) - 1;
```

要点：

- `pref` 的下标域是 `[0, n]`，长度 **`n+1`**——`pref[n]` 是「全选」，写法上少一位就会丢掉最大那个答案。
- `pref[0] = 0` 让「一个都选不了」的查询自然得到 0，不用特判。
- 用 `upper_bound`（第一个 `> q`）再减一，等于「最后一个 `<= q`」。用 `lower_bound` 会漏掉「和恰好等于 q」的情况。
- 排序合法性的来源：**子序列可以任意挑**，排序只改变顺序不改变可选集合。
## 差分

```cpp
vector<int> diff(n + 1, 0);      // 多开 1，容纳 r+1 == n
diff[l] += v;
diff[r + 1] -= v;

int cur = 0;
for (int i = 0; i < n; ++i) {
    cur += diff[i];
    a[i] += cur;                 // 还原即得区间加后的数组
}
```

差分是前缀和的逆运算：**前缀和把「点」变「区间」，差分把「区间」变「点」**。

## 易错点

- **溢出**：`pref` 用 `int` 是最常见的 WA，和超过 2^31 就静默出错。
- 差分数组开 `n+1` 是为了容纳 `r+1 == n` 的减操作；前缀和开 `n+1` 是为了哨兵**以及容纳 `pref[n]`（全部元素之和）**，两者理由不同。
- 用双指针代替哈希表：**只有数组全为正**时「和」才单调；有负数必须用哈希表。
- `cnt[cur - k]` 不要直接下标访问——`unordered_map` 的 `operator[]` 会插入新键，虽然是 0 不影响答案，但会白白扩容。
- 子数组 vs 子序列：前缀和只能处理**连续**的；**子序列**要先排序，再看前缀和能不能变成「选最小的 k 个」。
- 差分做「区间加」后，如果还要边加边查询，得用树状数组/线段树。
